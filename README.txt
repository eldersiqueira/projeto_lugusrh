# 🚀 LUGUS RH Consultoria

> Conectando Pessoas, Processos e Resultados. Transformamos o RH operacional em gestão estratégica.

---

## 💻 Sobre o Projeto
O **LUGUS RH** é uma landing page focada em soluções estratégicas integrando RH, Legislação Trabalhista e Sistemas de Qualidade. Este projeto visa oferecer uma presença digital profissional e otimizada para dispositivos móveis e desktop.

---

## ✨ Funcionalidades
- Apresentação dos serviços de consultoria oferecidos pela LUGUS
- **Estruturação de RH:** Cargos, salários e indicadores de desempenho (KPIs).
- **Recrutamento & Seleção:** Hunting e suporte em entrevistas.
- **Compliance Trabalhista:** Auditorias focadas em redução de riscos e passivos.
- **Qualidade:** Implementação e gestão de normas ISO 9001 e IATF 16949.

---

## 🛠️ Tecnologias Utilizadas
- As principais ferramentas e linguagens utilizadas no desenvolvimento deste projeto:
- **Linguagem:** HTML, CSS e JavaScript
- **IDE:** VSCode
- **Ferramentas:** Git, GitHub

---

## 🛠️ Design
O projeto foi idealizado seguindo princípios de **Mobile First** e **Design Responsivo**: 
- **Layout Mobile:** Fluxo vertical para navegação fluida em smartphones.
- **Layout Desktop:** Grade multicolunas para maximização da área de visualização.
- **Foco em UX:** Menu intuitivo, CTAs (Call to Action) estratégicos e navegação facilitada.
